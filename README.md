# Embedded Software Learning

My hands-on journey toward becoming an Embedded Software Engineer.

1. C programming fundamentals
2. Memory management and debugging
3. Linux system programming
4. Multithreading and synchronization
5. Network programming
6. Build systems and testing
7. Embedded Linux and cross-compilation
8. Camera pipelines, V4L2, GStreamer, and RTSP

Each topic will include practical code, build instructions, and notes.
